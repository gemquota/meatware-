# Contributor Roles and Progression

A contributor should be able to start with one small observation and grow into responsibility without committing to a six-film project on day one.

## Entry paths

| Path | First task | Useful strengths | Possible next step |
|---|---|---|---|
| Story / comedy | Alternate joke or beat review | Structure, dialogue, timing | Scene capsule, outline, script review |
| Continuity / canon | Flag one contradiction | Attention to detail, research | Continuity editor, canon audit |
| Character / performance | Voice guide | Acting, dialogue, character analysis | Performance brief, table-read notes |
| Visual / production | Shot list or prop checklist | Film craft, design, editing | Animatic, storyboard, production packet |
| Audio | Sound cue sheet | Sound design, mixing | Full scene sound plan |
| AI / workflow | Benchmark critique | Prompting, evaluation, automation | Reproducible pipeline, tool integration |
| Documentation | Proofread a source page | Editing, technical writing | Maintained documentation area |

## Contribution levels

### Level 0 — Observer
Reads the project and offers informal feedback.

### Level 1 — First contribution
Completes one bounded 10–30 minute task. Issue comments are valid.

### Level 2 — Repeat contributor
Completes multiple accepted tasks in a consistent area and understands source/canon boundaries.

### Level 3 — Area contributor
Owns a defined workstream such as continuity, character voice, sound, visual development or tooling. May propose task breakdowns.

### Level 4 — Reviewer
Has demonstrated reliable judgement and may review work in their area. Review authority is explicitly granted, not assumed.

### Level 5 — Maintainer / editor
Has trusted responsibility for repository operations, editorial decisions or a technical subsystem. Access is least-privilege and revocable.

Levels describe demonstrated responsibility, not social rank. Authority is not earned by producing large volumes of AI output.

## Recognition
- Attribute accepted contributions using the chosen public handle.
- Record artifact, task and review status.
- Do not imply employment, payment, ownership, revenue share or guaranteed screen credit.
- Do not use contribution counts as a substitute for quality.
- Allow pseudonymous or anonymous attribution.

## Contributor care
- Give newcomers a clear, small first task.
- Do not ask for substantial unpaid speculative work.
- Explain rights and permitted use before soliciting substantial creative assets.
- Ask before assigning ongoing responsibility.
- Let contributors stop participating without penalty.
