# Contributor Quick-Start

**Goal:** Make a first useful contribution in about 10–20 minutes, using only a phone and a chat-based AI if desired.

## The shortest route
1. Open [Open tasks](../tasks/OPEN_TASKS.md).
2. Pick a task that says **Tier 1 friendly**.
3. Open its linked GitHub issue and check that it is still open and unclaimed.
4. Copy the prompt payload from the task file.
5. Paste it into your preferred AI chat.
6. Ask it to produce only the requested artifact and to flag assumptions.
7. Review the output against the task's acceptance checklist.
8. Submit the draft in the issue discussion. A maintainer can help turn an accepted draft into a repository file.

## Rights note

The project's rights and licensing model is not finalized. For now, submit feedback, critique, continuity findings and clearly non-exclusive suggestions only. Do not submit substantial scripts, artwork, music, voice performances or production assets for incorporation. See the [rights decision brief](rights-decision-brief.md).

## What should I contribute?
You can help with film outlines and beat sheets, character voice samples and comedy passes, continuity checks, scene alternatives, production design and props, locations and visual references, AI-video/live-action test evaluation, prompt and workflow improvements, editing, proofreading, and documentation.

Not every contribution needs to invent new story. Finding a contradiction or making an existing scene clearer is useful work.

## A good first submission
Include:
- **Task ID**
- **Your output**
- **Assumptions:** what you had to invent or interpret
- **Canon conflicts:** anything that appears inconsistent
- **Self-check:** how you checked the acceptance criteria
- **Tools:** optional model/tool name and whether you substantially edited the result

## Claiming work
Comment: Claiming PHASE1-XXX. A maintainer may mark the issue as claimed. If there is no response, you can still post a draft, but avoid duplicating work already in progress.

## No issue? No problem.
For small suggestions, open a new issue using the contribution proposal template. For substantial work, ask for a task to be created before spending hours on it.

Read the [contributor FAQ](faq.md) if you are unsure what happens to a submission. The project has established story facts, unresolved continuity questions, and open creative proposals. They are not interchangeable. Label your invention rather than accidentally promoting it to canon.
