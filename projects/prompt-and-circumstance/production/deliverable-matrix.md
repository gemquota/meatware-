# Production Deliverable Matrix

This matrix connects the franchise roadmap to artifacts, dependencies and exit gates. It is a planning baseline, not a claim that later-stage production has begun.

| Stage | Required artifact | Depends on | Exit condition | Status |
|---|---|---|---|---|
| 0. Source capture | Archival PDF, source map, extracted Markdown | Original source | Traceable source and stable references | Complete |
| 1. Canon seed | Franchise bible, canon JSON, continuity register | Stage 0 | Canon facts separated from open questions | Drafted; editorial review |
| 2. Film architecture | Six-film arc, six 40-beat outlines | Stage 1 | Coherent causal spine and continuity checks per film | Film 1 draft; Films 2–6 tasks open |
| 3. Scene design | Scene capsules, scene dependency map, character objectives | Approved outlines | Scenes executable, paced and traceable to beats | Not started |
| 4. Script | Fountain screenplay, dialogue pass, revision log | Stage 3 | Full script passes editorial and production review | Not started |
| 5. Production design | Character, wardrobe, location, prop bible and visual references | Script draft | Repeatable look and continuity rules | Not started |
| 6. Modality proof | Five paired tests, score sheets, cost ledger, decision memo | Test briefs and available tools | Hard gates passed or fallback selected | Protocol ready; tests not run |
| 7. Previsualization | Storyboards, animatics, shot lists, sound plan | Stages 4–6 | Key sequences understood and schedulable | Not started |
| 8. Pilot production | One complete scene or short proof | Approved modality and production plan | Quality, time and cost demonstrated | Not started |
| 9. Feature assembly | Edited Film 1, sound, VFX/UI, QC and release package | Stage 8 | Editorial sign-off and rights clearance | Not started |
| 10. Franchise scale | Repeatable pipeline and Films 2–6 packages | Film 1 postmortem | Pipeline sustainable and adaptable | Not started |

## Cross-cutting control artifacts
- **Continuity matrix:** character, location, prop, time, AI-system and institutional continuity.
- **Decision log:** adopted canon and production decisions with rationale.
- **Asset register:** asset ID, owner/source, licence/permission, version, intended use and clearance status.
- **Revision log:** requested change, affected artifact, result and regression check.
- **Cost ledger:** labour, tools, generation, equipment, locations, post-production and rework.
- **Risk register:** probability, impact, mitigation, owner and trigger.
- **Credits ledger:** accepted contribution provenance after credit policy approval.

## Stage exit rule
A stage is not complete because a document exists. It is complete when its exit condition is reviewed, evidence is linked, unresolved risks are recorded, and the next stage can consume the output without guessing.
