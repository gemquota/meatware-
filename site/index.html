What happens when nothing is told what life is?

Explore a deliberately abstract system of interacting entities with two continuous state channels. Nearby entities exchange state; stochastic perturbations and state-dependent motion keep the system dynamic. No biological categories or evolutionary outcomes are built in.

Experimental conditions

Deterministic for a fixed seed, configuration and execution path. Replay restarts the initial conditions and executes 100 transitions. Relationship formation evaluates all entity pairs at the current boundary, selecting nearby pairs through an explicit eligibility predicate. Each accepted relationship is recorded as a generic relation in the substrate and event log. The current model is an abstract dynamics demonstration, not evidence of evolution or adaptation. The exported event log contains the initial snapshot and every committed proposal batch.

What this experiment actually does

Each entity has a position and two continuous scalar channels. The optional structural experiment evaluates participant pairs against the same immutable state, then creates persistent generic relationships for eligible nearby pairs using ordinary proposals and the normal atomic transition log. Entities within the configured range exchange channel values through a distance-weighted interaction. Random perturbations vary those values, while channel values influence movement through a periodic two-dimensional domain. The model has no entity classes, fitness score, replication operation, inheritance mechanism or prescribed evolutionary endpoint.

Substrate

Identities, positions and extensible state are kept separate from interpretation.

Dynamics

Pairwise interaction, state change and stochastic perturbation are explicit and configurable.

Observation

Metrics and state hashes are read-only. Exported versioned manifests are generated by the Rust runtime and record the actual initial state, parameters, conflict policy, random generator and replay verification.
